A hand-built, dependency-free Markdown renderer for the [make.fun](https://make.fun) competition `markdown-render-speed-02`. It renders Markdown to HTML byte-identical to marked 18.1.3 (CommonMark 0.31.2 + GFM 0.29) and is built for speed: a single-pass block parser and inline parser with no dependencies and no per-case caching.
